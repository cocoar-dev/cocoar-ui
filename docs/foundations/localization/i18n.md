# i18n (Translations)

The Cocoar i18n system provides **key-based translations** with automatic loading, parameter interpolation, and reactive updates when the language changes.

**Package:** `@cocoar/localization`

## Quick Start

### 1. Configure i18n

```ts
import { ApplicationConfig } from '@angular/core';
import { provideHttpClient } from '@angular/common/http';
import {
  provideCoarLocalization,
  provideCoarI18nHttpSource,
} from '@cocoar/localization';

export const appConfig: ApplicationConfig = {
  providers: [
    provideHttpClient(),
    provideCoarLocalization({ defaultLanguage: 'en' }),
    provideCoarI18nHttpSource(),  // Defaults to /i18n/{lang}.json
  ],
};
```

### 2. Create Translation Files

**`public/i18n/en.json`:**
```json
{
  "welcome": "Welcome",
  "hello": "Hello, {{name}}!",
  "goodbye": "Goodbye",
  "save": "Save",
  "cancel": "Cancel"
}
```

**`public/i18n/de.json`:**
```json
{
  "welcome": "Willkommen",
  "hello": "Hallo, {{name}}!",
  "goodbye": "Auf Wiedersehen",
  "save": "Speichern",
  "cancel": "Abbrechen"
}
```

### 3. Use in Templates

```html
<!-- Simple translation -->
<h1>{{ 'welcome' | coarI18n }}</h1>

<!-- With parameters -->
<p>{{ 'hello' | coarI18n:{ name: 'Alice' } }}</p>

<!-- With fallback -->
<button>{{ 'save' | coarI18n:'Save' }}</button>
```

### 4. Use in Components

```ts
import { Component, inject } from '@angular/core';
import { COAR_I18N_PROVIDER } from '@cocoar/localization';

@Component({
  selector: 'app-greeting',
  template: `<h1>{{ greeting }}</h1>`,
})
export class GreetingComponent {
  private readonly i18n = inject(COAR_I18N_PROVIDER);

  get greeting(): string {
    return this.i18n.t('hello', { name: 'World' });
  }
}
```

## API Reference

### CoarI18nPipe

Transform translation keys into localized strings.

```html
<!-- Simple translation -->
{{ 'welcome' | coarI18n }}

<!-- With parameters -->
{{ 'hello' | coarI18n:{ name: userName } }}

<!-- With fallback (returns fallback if key missing) -->
{{ 'unknown_key' | coarI18n:'Default Text' }}
```

**Parameters:**
- `key: string` - Translation key
- `paramsOrFallback?: Record<string, unknown> | string` - Parameters for interpolation OR fallback text
- `fallback?: string` - Fallback text (when params provided)

### CoarI18nProvider

Injectable service for programmatic translations.

```ts
import { inject } from '@angular/core';
import { COAR_I18N_PROVIDER } from '@cocoar/localization';

class MyService {
  private readonly i18n = inject(COAR_I18N_PROVIDER);

  getMessage(): string {
    return this.i18n.t('welcome');
  }

  getGreeting(name: string): string {
    return this.i18n.t('hello', { name });
  }

  getWithFallback(): string {
    return this.i18n.tWithDefault('unknown_key', 'Default Value');
  }
}
```

**Methods:**

**`t(key: string, params?: Record<string, unknown>): string`**
- Translates a key
- Returns the key itself if translation not found
- Supports `{{placeholder}}` interpolation

**`tWithDefault(key: string, defaultValue: string, params?: Record<string, unknown>): string`**
- Translates with explicit fallback
- Returns `defaultValue` if translation not found
- Supports interpolation in translation (not in fallback)

### CoarI18nService

Full translation service with reactive state (injected via `COAR_I18N_PROVIDER`).

```ts
import { Component, inject, computed } from '@angular/core';
import { COAR_I18N_PROVIDER, CoarI18nService } from '@cocoar/localization';

@Component({
  selector: 'app-reactive',
  template: `
    <p>Loaded: {{ loaded() }}</p>
    <p>Count: {{ translationCount() }}</p>
  `,
})
export class ReactiveComponent {
  private readonly i18n = inject(COAR_I18N_PROVIDER) as CoarI18nService;

  readonly loaded = computed(() => this.i18n.translations() !== null);
  readonly translationCount = computed(() => this.i18n.translations()?.size ?? 0);
}
```

**Properties:**

**`translations: Signal<ReadonlyMap<string, string> | null>`**
- Signal containing current translations
- `null` if not loaded yet
- Updates automatically when language changes

## Parameter Interpolation

Use `{{placeholder}}` in translations:

```json
{
  "welcome": "Welcome, {{name}}!",
  "items": "You have {{count}} items in your cart",
  "complex": "Hello {{user}}, you have {{unread}} unread messages"
}
```

```html
<!-- Simple -->
{{ 'welcome' | coarI18n:{ name: 'Alice' } }}
<!-- Output: Welcome, Alice! -->

<!-- Multiple placeholders -->
{{ 'items' | coarI18n:{ count: 5 } }}
<!-- Output: You have 5 items in your cart -->

<!-- Complex -->
{{ 'complex' | coarI18n:{ user: 'Bob', unread: 3 } }}
<!-- Output: Hello Bob, you have 3 unread messages -->
```

## Custom URL Configuration

```ts
// Custom path
provideCoarI18nHttpSource({
  url: (lang) => `/assets/translations/${lang}.json`
})

// API endpoint with authentication
provideCoarI18nHttpSource({
  url: (lang) => `/api/translations/${lang}.json`,
  headers: {
    'Authorization': 'Bearer ' + getToken()
  }
})

// CDN with versioning
provideCoarI18nHttpSource({
  url: (lang) => `https://cdn.example.com/i18n/${lang}.json?v=1.0.0`
})
```

## Translation File Format

### Flat Structure (Recommended)

```json
{
  "app.title": "My Application",
  "app.subtitle": "Welcome to our app",
  "buttons.save": "Save",
  "buttons.cancel": "Cancel",
  "errors.required": "This field is required",
  "errors.invalid_email": "Invalid email address"
}
```

Use dot notation for organization, but keep the structure flat.

### Nested Structure (Auto-flattened)

```json
{
  "app": {
    "title": "My Application",
    "subtitle": "Welcome to our app"
  },
  "buttons": {
    "save": "Save",
    "cancel": "Cancel"
  }
}
```

This is automatically flattened to `app.title`, `app.subtitle`, etc.

## Reactive Updates

The i18n system automatically updates when the language changes:

```ts
import { Component, inject } from '@angular/core';
import { CoarLocalizationService } from '@cocoar/localization';

@Component({
  selector: 'app-language-switcher',
  template: `
    <div>
      <p>{{ 'current_language' | coarI18n }}</p>
      <button (click)="switchLanguage('en')">English</button>
      <button (click)="switchLanguage('de')">Deutsch</button>
    </div>
  `,
})
export class LanguageSwitcherComponent {
  private readonly locale = inject(CoarLocalizationService);

  switchLanguage(lang: string) {
    // This triggers:
    // 1. Loads /i18n/{lang}.json
    // 2. Updates all {{ ... | coarI18n }} pipes
    // 3. Updates translations() signal
    this.locale.setLanguage(lang);
  }
}
```

## Missing Translations

When a translation key is not found:

**Using `coarI18n` pipe without fallback:**
```html
{{ 'missing_key' | coarI18n }}
<!-- Output: missing_key (returns the key itself) -->
```

**Using `coarI18n` pipe with fallback:**
```html
{{ 'missing_key' | coarI18n:'Default Text' }}
<!-- Output: Default Text -->
```

**Using `t()` method:**
```ts
this.i18n.t('missing_key');
// Returns: 'missing_key'
```

**Using `tWithDefault()` method:**
```ts
this.i18n.tWithDefault('missing_key', 'Default Text');
// Returns: 'Default Text'
```

## Best Practices

### 1. Use Namespaces with Dot Notation

```json
{
  "common.save": "Save",
  "common.cancel": "Cancel",
  "auth.login": "Login",
  "auth.logout": "Logout",
  "profile.title": "User Profile",
  "profile.edit": "Edit Profile"
}
```

### 2. Provide Fallbacks for User-Facing Text

```html
<!-- Good: Always provide fallback for critical UI -->
<button>{{ 'save' | coarI18n:'Save' }}</button>

<!-- Avoid: No fallback -->
<button>{{ 'save' | coarI18n }}</button>
```

### 3. Keep Parameters Semantic

```json
{
  "greeting": "Hello, {{userName}}!",
  "items_count": "You have {{itemCount}} items"
}
```

```html
<!-- Good: Clear parameter names -->
{{ 'greeting' | coarI18n:{ userName: user.name } }}

<!-- Avoid: Generic names -->
{{ 'greeting' | coarI18n:{ x: user.name } }}
```

### 4. Extract Translations Early

Don't wait until the end to add translations. Extract text as you build components.

### 5. Use TypeScript for Translation Keys

```ts
// translations.keys.ts
export const TranslationKeys = {
  Common: {
    Save: 'common.save',
    Cancel: 'common.cancel',
  },
  Auth: {
    Login: 'auth.login',
    Logout: 'auth.logout',
  },
} as const;
```

```ts
{{ TranslationKeys.Common.Save | coarI18n:'Save' }}
```

This provides type safety and autocompletion.

## Testing

### Mock i18n in Tests

```ts
import { COAR_I18N_PROVIDER } from '@cocoar/localization';

const mockI18n = {
  t: (key: string, params?: Record<string, unknown>) => {
    // Return key as-is or provide mock translations
    return key;
  },
  tWithDefault: (key: string, defaultValue: string) => defaultValue,
};

// In test providers
providers: [
  { provide: COAR_I18N_PROVIDER, useValue: mockI18n }
]
```

### Test with Real Translations

```ts
import { provideCoarLocalization } from '@cocoar/localization';
import { HttpTestingController } from '@angular/common/http/testing';

// Setup
providers: [
  provideHttpClient(),
  provideCoarLocalization({ defaultLanguage: 'en' }),
  provideCoarI18nHttpSource(),
]

// In test
const http = TestBed.inject(HttpTestingController);
const req = http.expectOne('/i18n/en.json');
req.flush({ 'welcome': 'Welcome' });
```
