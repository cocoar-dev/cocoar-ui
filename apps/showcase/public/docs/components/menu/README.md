## Viewing Documentation

### In Showcase App

The documentation is automatically available in the showcase app:

1. Navigate to the Menu component page
2. Click the **"Docs"** tab to view overview.md
3. Click the **"API"** tab to view api.md

### Direct Access

- **Docs:** http://localhost:4200/menu (Docs tab)
- **API:** http://localhost:4200/menu (API tab)
