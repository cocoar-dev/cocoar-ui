Getting Started

Set up the Coar Design System in your Angular project in a few steps. Install the packages, import design tokens, and start using components.

1. Install

The @cocoar/ui package gives you everything you need to get started. It includes:

  • @cocoar/ui/styles — design tokens (CSS variables)
  • @cocoar/ui/components — core components (buttons, cards, inputs, ...)
  • @cocoar/ui/menu — menu & sidebar
  • @cocoar/ui/overlay — tooltips, popovers, overlays

Additional Packages

Some packages are not included in @cocoar/ui and must be installed separately when needed:

  • @cocoar/data-grid — AG Grid wrapper with Coar theming
  • @cocoar/markdown-viewer — markdown rendering component
  • @cocoar/localization — i18n & language management
  • @cocoar/ui-routing — fragment-based routing utilities

2. Import Design Tokens

Add the design tokens stylesheet to your application's global styles.css. This provides all CSS variables for colors, typography, spacing, and more.

3. Import Components

Components are split across entry points. Import what you need into your standalone components.

4. Dark Mode

Toggle dark mode by adding the .dark-mode CSS class to the root element. All design tokens and components adapt automatically.

5. Design Tokens

Use CSS variables from @cocoar/ui for consistent styling. Available token categories include:

  • --coar-color-* — color primitives
  • --coar-background-* / --coar-text-* / --coar-border-* — semantic tokens
  • --coar-spacing-* — spacing scale
  • --coar-radius-* — border radii
  • --coar-shadow-* — elevation shadows
