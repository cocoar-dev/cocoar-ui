Pagination

A navigation component for moving between pages of content.

Basic Usage

Standard pagination with 100 items and 10 items per page. Current page: {{ currentPage() }}

Custom Page Size

200 items with 20 items per page, starting at page 5. Current page: {{ currentPage2() }}

Without First/Last Buttons

Hide the first and last page navigation buttons.

Disabled

All controls are disabled.
Pagination API

Inputs

Name Type Default Description
totalItems number - (required) Total number of items to paginate
pageSize number 10 Number of items per page
currentPage number 1 Current page number (1-based, two-way binding)
maxVisiblePages number 5 Maximum number of page buttons visible
showFirstLast boolean true Show first/last page buttons
disabled boolean false Disable all pagination controls

Outputs

Name Type Description
pageChanged number Emits when the current page changes
