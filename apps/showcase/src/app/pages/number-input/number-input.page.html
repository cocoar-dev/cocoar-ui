Number Input

A specialized input for numeric values with increment/decrement buttons, min/max constraints, decimal precision, and Figma-style drag-to-adjust on the label.

Examples API

Basic Usage

Simple number input with increment/decrement buttons using attribute pattern.

Min & Max Constraints

Limit the value range. Buttons disable at boundaries.

Step Increments

Control increment size with the step property.

Decimal Precision

Control decimal places for currency, percentages, etc.

Locale & Internationalization

Different number formats for German (comma decimal) vs US (period decimal).

Raw value: {{ usPrice() ?? 'null' }}

Prefix & Suffix

Add units or currency symbols.

Figma-style Drag

Disabled & Readonly
