Number Input

A specialized input for numeric values with increment/decrement buttons, min/max constraints, decimal precision, and Figma-style drag-to-adjust on the label.

Basic Usage

Simple number input with increment/decrement buttons.

Min & Max Constraints

Limit the value range. Buttons disable at boundaries.

Step Increments

Control increment size with the step property.

Decimal Precision

Control decimal places for currency, percentages, etc.

Value: {{ priceValue() ?? 'null' }}

Prefix & Suffix

Add units or currency symbols.

Figma-style Drag

Click and drag the label horizontally to adjust the value.

Locale & Internationalization

Support different number formats for locales like German (comma decimal) vs US (period decimal).

German Format

Comma as decimal separator, period as thousands.

Raw value: {{ germanPrice() ?? 'null' }}

US Format

Period as decimal separator, comma as thousands.

Raw value: {{ usPrice() ?? 'null' }}

Stepper Buttons

Control increment/decrement buttons with the stepperButtons attribute for granular control.

Button Configurations

No buttons, both buttons, or single increment/decrement.

Sizes

Four size variants for different contexts.

Disabled & Readonly

Non-interactive states.
Number Input API

Inputs

Name Type Default Description
value number | null null Current numeric value (two-way bindable)
label string '' Label text displayed above the input
placeholder string '' Placeholder text when empty
hint string '' Hint text below the input
error string '' Error message to display
prefix string '' Prefix text before the input (e.g., $)
suffix string '' Suffix text after the input (e.g., EUR, %)
size 'xs' | 'sm' | 'md' | 'lg' 'md' Input size
min number -Infinity Minimum allowed value
max number Infinity Maximum allowed value
step number 1 Increment/decrement step value
decimals number 0 Number of decimal places to display
stepperButtons '' | 'increment' | 'decrement' - Show stepper buttons (attribute or specific)
numberFormat {{ '{' }} decimal: string, thousand: string {{ '}' }} {{ '{' }} decimal: '.', thousand: ',' {{ '}' }} Locale-specific number formatting
disabled boolean false Disable the input
readonly boolean false Make the input read-only
required boolean false Mark as required (shows asterisk)
