Data Grid API

CoarGridBuilder Methods

MethodDescription
columns()Define column configurations using column builder functions
rowData()Set the data array to display in the grid
rowId()Define how to extract unique row IDs
rowSelection()Enable 'single' or 'multiple' row selection
rowClassRules()Apply CSS classes conditionally to rows
onRowClicked()Handle row click events

Column Builder Methods

MethodDescription
field()Set the data field name
header()Set the column header text
width() / flex()Set fixed width or flex sizing
sortable()Enable column sorting
cellClass()Apply CSS classes to cells
