Data Grid API

CoarGridBuilder Methods

Name Type Description
columns()functionDefine column configurations using column builder functions
rowData()functionSet the data array to display in the grid
rowId()functionDefine how to extract unique row IDs from data objects
rowSelection()functionEnable 'single' or 'multiple' row selection mode
rowClassRules()functionApply CSS classes conditionally to rows based on data
onRowClicked()functionHandle row click events with callback

Column Builder Methods

Name Type Description
field()functionSet the data field name to bind to this column
header()functionSet the column header text displayed to users
width() / flex()functionSet fixed width (pixels) or flex sizing (proportion)
sortable()functionEnable column sorting by clicking header
cellClass()functionApply CSS classes to cells in this column
