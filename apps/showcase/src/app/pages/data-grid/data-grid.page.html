Data Grid

A powerful data grid powered by AG Grid with Cocoar theme integration and a fluent builder API.

Basic Usage

Use CoarGridBuilder to define columns and data with a fluent API.

Column Factory Types

Use factory methods like date(), number(), currency(), and boolean() for automatic formatting.

Typed Columns

The column factory callback provides date(), number(), currency(), and boolean() shorthand methods that auto-format cell values.

Sorting & Default Sort

Pre-sort grids, define custom comparators, and enable quick filtering on columns.

Default Sort with Custom Comparator

This grid loads pre-sorted by salary (descending). The Name column uses a custom comparator that sorts by last name. Try clicking the Name header to see it in action.

Editing

Enable inline editing with full-row edit mode and focus-based stop.

Full Row Edit

Double-click a row to enter edit mode. All editable cells in the row become active at once. Click outside to commit changes.

Cell Renderer Columns

Use tag(), icon(), and localDate() factory methods to render rich cell content with Cocoar components.

Tag, Icon & Date Renderers

Status and priority columns render as <coar-tag> elements with variant mapping. The type column renders <coar-icon>, and the date column uses locale-aware CoarDatePipe.

Context Menu & Viewport Events

Open a custom context menu on right-click using the overlay system and CoarMenuComponent.

Grid Context Menu

Right-click a cell or the empty viewport area to open a context menu. Ctrl+right-click passes through to the browser.

Data Grid API

CoarGridBuilder Methods

Name Type Description
columns() function Define column configurations using column builder functions
defaultColDef() function Set default column definition applied to all columns
rowData() function Set the data array to display in the grid
rowData$() function Set the data as an observable for async/streaming data
rowId() function Define how to extract unique row IDs from data objects
rowSelection() function Enable 'single' or 'multiple' row selection mode
rowClassRules() function Apply CSS classes conditionally to rows based on data
rowClass() function Set a dynamic row class function
defaultSort() function Set initial sort column and direction (e.g. 'salary', 'desc')
sortFunction() function Set a custom post-sort function to reorder rows after AG Grid sorts
fullRowEdit() function Enable full-row editing mode (all cells in a row edit at once)
stopEditingWhenCellsLoseFocus() function Commit edits when cells lose focus
shiftResizeMode() function Enable shift-key column resize mode
animateRows() function Enable or disable row animation
columnState() function Restore column widths, order, and visibility from saved state
openRows() function Set which parent rows are expanded (observable of row IDs)
externalFilter() function Set an external filter function applied outside the grid
updateExternalFilterWhen() function Re-trigger external filter when the given observable emits
updateSortAndFilterWhen() function Re-trigger sort and filter when the given observable emits
onRowClicked() function Handle row click events with callback
onRowDoubleClicked() function Handle row double-click events
onCellClicked() function Handle cell click events
onCellDoubleClicked() function Handle cell double-click events
onCellContextMenu() function Handle cell right-click (Ctrl+click passes through)
onViewportClick() function Handle click on empty grid viewport area
onViewportContextMenu() function Handle right-click on empty grid viewport area
onGridReady() function Handle grid ready event (access API)
onGridSizeChanged() function Handle grid size changed event
option() function Set any AG Grid option directly as a key-value escape hatch
options() function Merge additional AG Grid options object

Column Builder Methods

Name Type Description
field() function Set the data field name to bind to this column
header() function Set the column header text displayed to users
headerTooltip() function Set a tooltip on the column header
width() / flex() function Set fixed width (pixels) or flex sizing (proportion)
fixedWidth() function Set width, minWidth, and maxWidth to the same value
minWidth() / maxWidth() function Set minimum or maximum column width
sortable() function Enable column sorting by clicking header
resizable() function Enable or disable column resizing
hidden() function Show or hide the column
pinned() function Pin column to 'left' or 'right'
lockPosition() function Lock the column position
cellClass() function Apply CSS classes to cells in this column
cellStyle() function Apply inline styles to cells
classRule() function Add a conditional CSS class rule
cellRenderer() function Set a custom cell renderer component
cellRendererConfig() function Set cell renderer with a config object pattern
valueFormatter() function Set a display formatter function
valueGetter() function Set a value getter to transform data
tooltip() function Show tooltip with field value or custom function
filter() function Enable or disable column filtering
quickFilter() function Set quick filter text extractor or disable quick filtering
comparator() function Set a custom sort comparator function
rowDrag() function Enable row drag on this column
onCellDoubleClicked() function Handle cell double-click event on this column
option() function Set any AG Grid ColDef option directly as an escape hatch
customize() function Apply custom modifications to the column definition

Column Factory Methods

Name Type Description
field() function Create a plain column builder for the given field
date() function Create a date column with formatting ('short', 'long', 'datetime', or custom)
number() function Create a right-aligned number column with locale formatting
currency() function Create a right-aligned currency column (default USD)
boolean() function Create a boolean column displaying Yes/No or custom values
tag() function Create a tag column rendering <coar-tag> elements with variant mapping
icon() function Create an icon column rendering <coar-icon> from the cell value
localDate() function Create a locale-aware date column using CoarDatePipe cell renderer
