Date Picker

A date picker component using the Temporal API for timezone-independent date selection. Supports min/max constraints, keyboard navigation, and locale-aware formatting.

Examples API Docs

Basic Usage

A simple date picker with label and placeholder.

Selected: {{ formatDate(basicDate()) }}

Pre-selected Value

Date picker with an initial value set.

Selected: {{ formatDate(preselectedDate()) }}

Min/Max Constraints

Restrict the selectable date range using min and max properties.

Selected: {{ formatDate(minMaxDate()) }}
Range: {{ formatDate(minDate) }} to {{ formatDate(maxDate) }}

Size Variants

Available in four sizes: extra-small, small, medium (default), and large.

States

Date pickers can be disabled, readonly, show errors, or be marked as required.

Keyboard Navigation

The date picker supports full keyboard navigation:

  • Enter / Space - Open calendar or select focused date
  • Escape - Close calendar
  • Arrow keys - Navigate between days
  • Page Up / Down - Navigate by month
  • Shift + Page Up / Down - Navigate by year
  • Home - Go to today's date

Locale Service Integration

The date picker integrates with COAR_LOCALE_SERVICE for automatic locale-aware date formatting, just like the number input.

Format Priority:

  1. dateFormatConfig input - direct override
  2. locale input + locale service - per-component locale
  3. Locale service default - application-wide setting
  4. Browser locale fallback

Localized Calendar Display

Weekday and month names are automatically localized using the browser's Intl.DateTimeFormat API. No translation files needed.

Open each calendar to see localized weekday names (Mo/Di/Mi... vs Lun/Mar/Mer...).

Week Numbers

Enable ISO week numbers on the left side of the calendar with showWeekNumbers. Useful for business applications where week numbers are referenced.

Date Markers (Holidays)

Mark special dates like holidays or events with markers. Marked days show a small dot indicator and display a tooltip on hover.

CoarDateMarker Interface:

  • startDate - Start date (or single date if no endDate)
  • endDate - Optional end date for ranges (inclusive)
  • description - Tooltip text shown on hover
  • cssClass - Optional custom CSS class for styling

Hover over Dec 24-26, Dec 31, Jan 1 to see tooltips.
