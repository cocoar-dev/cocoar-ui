Avatar

Avatars represent users or entities with images or initials. They support multiple sizes, shapes, and automatic fallback to initials when images are unavailable.

Examples API Docs

Basic Usage

Avatars display user images with automatic initials fallback.

@for (user of users; track user.name) {
{{ user.name }}
}

Sizes

Six preset sizes from extra-small (24px) to extra-extra-large (96px).

@for (size of sizes; track size) {
{{ size }} ({{ sizeLabels[size] }})
}

Shapes

Choose between circular avatars (default) or square with rounded corners.

@for (shape of shapes; track shape) {
{{ shape }}
}

Initials Fallback

When no image is available, the avatar shows the first 3 characters of the name. Use the coarInitials pipe to extract first letters from full names.

@for (user of fallbackUsers; track user.name) {
{{ user.name }} → {{ user.name | coarInitials }}
}
Two Approaches

Pass raw text like name="ABC" to show exact characters, or use the coarInitials pipe like [name]="'Alice Johnson' | coarInitials" to extract first letters.
