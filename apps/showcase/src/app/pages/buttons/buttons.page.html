Variant Usage

When to use each variant.

Primary — Main call-to-action. Use sparingly, typically once per view.
Secondary — Alternative actions. Pairs well with primary buttons.
Tertiary — Low-emphasis actions with brand color hint.
Danger — Destructive actions like delete or remove.
Ghost — Minimal emphasis, often for cancel or dismiss.

Accessibility

Buttons have full keyboard support and follow WCAG accessibility guidelines.

Keyboard Navigation

Standard button keyboard interactions for activation and focus.

Tab Move focus to button
Shift + Tab Move focus backward
Enter Activate button
Space Activate button
Note: Disabled and loading buttons cannot be activated via keyboard.

Screen Reader Support

Buttons announce their state and purpose to assistive technologies.

  • Button text or aria-label announces on focus
  • Disabled state properly communicated
  • Loading state indicates button is busy
  • Icon-only buttons should include aria-label
  • Type attribute ensures correct form behavior
Button API

Inputs

Name Type Default Description
variant 'primary' | 'secondary' | 'tertiary' | 'danger' | 'ghost' 'primary' Button style variant
size 'xs' | 's' | 'm' | 'l' 'm' Button size
iconStart string undefined Icon name to display before the label
iconEnd string undefined Icon name to display after the label
loading boolean false Show loading spinner
disabled boolean false Disable the button
fullWidth boolean false Expand to fill container width
type 'button' | 'submit' | 'reset' 'button' HTML button type
ariaLabel string '' Accessible label for the button (important for icon-only buttons)

Outputs

Name Type Description
clicked MouseEvent Emits when the button is clicked (not emitted when disabled or loading)
