Code Block

A versatile code display component with syntax hints, copy functionality, and collapsible sections.

Basic Usage

The code block automatically adapts to the current theme. Toggle the theme in the sidebar to see it change.

Language Support

Display code in various languages with appropriate labels.

Collapsible

Click the chevron to expand or collapse the code block.

Non-collapsible

Always visible with no toggle option.

Without Copy Button

For read-only display where copying is not needed.

Line Numbers

Enable line numbers for easier referencing in docs and reviews.

Max Height

Limits the height with internal scrolling for long code snippets.

Scrollable Content

Set a max height to enable scrolling for long code.
Code Block API

Inputs

Name Type Default Description
code string '' The code content to display
language string 'text' Programming language for label (html, typescript, css, json, etc.)
title string '' Optional title/filename shown in header
showLineNumbers boolean false Show line numbers in the gutter
showCopy boolean true Show the copy-to-clipboard button
collapsible boolean true Allow expanding/collapsing the code
collapsed boolean false Initial collapsed state
maxHeight number - Maximum height in pixels before scrolling
