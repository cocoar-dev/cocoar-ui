Code Block

Basic Usage

Language Support

Collapsible

Click the chevron to expand or collapse the code block.

Non-collapsible

Always visible with no toggle option.

Without Copy Button

For read-only display where copying is not needed.

Max Height (Scrollable)

Limits the height with internal scrolling for long code snippets.
