Checkbox

A checkbox component with three states: checked, unchecked, and indeterminate. Supports labels, hints, errors, and size variants.

Basic Checkbox

A simple checkbox with a label. Starts as undefined (pristine), becomes 'checked' or 'unchecked' after first click.

State: {{ basicChecked() === undefined ? 'undefined (pristine)' : "'" + basicChecked() + "'" }}

Pre-checked

A checkbox that starts in checked state.

State: '{{ newsletterChecked() }}'

Required Field

Required checkboxes show an asterisk next to the label.

Error State

Display validation errors below the checkbox.

State: {{ errorChecked() === undefined ? 'undefined' : "'" + errorChecked() + "'" }}

With Hint

Add helper text below the checkbox.

Disabled & Readonly

Disabled checkboxes are greyed out. Readonly ones look normal but can't be changed.

Indeterminate State

Parent checkbox shows 'indeterminate' when some children are selected. The state is computed from children.

Parent-Child Selection

Click "Select all" to toggle all fruits. Individual clicks update the parent state.

Parent: '{{ parentCheckboxState() }}' — Selected: {{ selectedFruits().join(', ') || '(none)' }}

Sizes

Checkboxes come in four sizes matching other form components.
Checkbox API

Inputs

Name Type Default Description
checked CoarCheckboxState | undefined undefined Checkbox state: 'checked', 'unchecked', 'indeterminate', or undefined (pristine)
label string '' Label text displayed next to the checkbox
hint string '' Hint text below the checkbox
error string '' Error message to display
size 'xs' | 'sm' | 'md' | 'lg' 'md' Checkbox size
disabled boolean false Disable the checkbox
readonly boolean false Make the checkbox read-only
required boolean false Mark as required (shows asterisk)

Outputs

Name Type Description
checkedChange CoarCheckboxState Emits when the checked state changes
