Checkbox

A checkbox component with boolean checked state and optional indeterminate mode. Supports labels, hints, errors, and size variants.

Required Field

Required checkboxes show an asterisk next to the label.

With Hint

Add helper text below the checkbox.

Disabled & Readonly

Disabled checkboxes are greyed out. Readonly ones look normal but can't be changed.

Indeterminate State

Parent checkbox shows indeterminate when some children are selected. Use the [indeterminate] input separately from [checked].

Sizes

Checkboxes come in four sizes matching other form components.
Checkbox API

Inputs

Name Type Default Description
checked boolean | undefined undefined Checkbox state: true (checked), false (unchecked), or undefined (pristine)
indeterminate boolean false Sets the checkbox to indeterminate state (visual only)
label string '' Label text displayed next to the checkbox
hint string '' Hint text below the checkbox
error string '' Error message to display
size 'xs' | 'sm' | 'md' | 'lg' 'md' Checkbox size
disabled boolean false Disable the checkbox
readonly boolean false Make the checkbox read-only
required boolean false Mark as required (shows asterisk)

Outputs

Name Type Description
checkedChange boolean Emits when the checked state changes
