Checkbox

A checkbox component with three states: checked, unchecked, and indeterminate. Supports labels, hints, errors, and size variants.

Examples API

Basic Checkbox

A simple checkbox with a label. Starts as undefined (pristine), becomes 'checked' or 'unchecked' after first click.

Pre-checked

A checkbox that starts in checked state.

Indeterminate State

Parent checkbox shows 'indeterminate' when some children are selected. The state is computed from children.

@for (fruit of fruits; track fruit) { }
Parent state: '{{ parentCheckboxState() }}' — Selected: {{ selectedFruits().join(', ') || '(none)' }}

Required Field

Required checkboxes show an asterisk next to the label.

Error State

Display validation errors below the checkbox.

State: {{ errorChecked() === undefined ? 'undefined' : "'" + errorChecked() + "'" }}

With Hint

Add helper text below the checkbox.

State: {{ hintChecked() === undefined ? 'undefined' : "'" + hintChecked() + "'" }}

Disabled

Disabled checkboxes cannot be interacted with and appear greyed out.

Readonly

Readonly checkboxes look normal but cannot be changed. Unlike disabled, they remain focusable.

Sizes

Checkboxes come in four sizes matching other form components (inputs, buttons).

Accessibility

  • Uses native <input type="checkbox"> for proper semantics
  • Labels are clickable and properly associated via for attribute
  • Supports keyboard navigation with Space and Enter keys
  • Focus states are clearly visible
  • Indeterminate state uses aria-checked="mixed"
  • Error and hint messages linked via aria-describedby
