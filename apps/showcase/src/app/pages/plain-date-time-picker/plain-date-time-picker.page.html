DateTime Picker

A strongly-typed datetime picker that returns Temporal.PlainDateTime exclusively. For date-only values, use coar-plain-date-picker.

Basic Usage

A datetime picker with label and placeholder.

Selected: {{ formatDateTime(basicDateTime()) }}

Pre-selected Value

DateTime picker with an initial value set.

Selected: {{ formatDateTime(preselectedDateTime()) }}

Time Format

Control the time format: 24-hour or 12-hour with AM/PM.

Minute Step

Control the granularity of minute selection.

Min/Max Constraints

Restrict selectable datetime range. Time picker is also constrained on boundary dates.

Range: {{ formatDateTime(minDateTime) }} to {{ formatDateTime(maxDateTime) }}

Week Numbers & Markers

Display week numbers and highlight special dates.

Selected: {{ formatDateTime(markerDateTime()) }}

Sizes & States

Available in four sizes and various states.

Size Variants

Extra-small, small, medium (default), and large.

States

Disabled, readonly, error, and required states.

Full Featured

All features combined: week numbers, weekend highlighting, markers, and 15-minute intervals.

Selected: {{ formatDateTime(fullFeaturedDateTime()) }}
DateTime Picker API

Inputs

Name Type Default Description
value Temporal.PlainDateTime | null null Selected datetime (two-way bindable)
label string '' Label text above the input
placeholder string '' Placeholder text when empty
min Temporal.PlainDateTime - Minimum selectable datetime
max Temporal.PlainDateTime - Maximum selectable datetime
size 'xs' | 's' | 'm' | 'l' 'm' Input size
use24Hour boolean | 'auto' 'auto' Time format (auto uses locale)
minuteStep number 5 Minute selection granularity
showWeekNumbers boolean false Show ISO week numbers
highlightWeekends boolean false Highlight weekend days
markers CoarDateMarker[] [] Special dates to highlight
disabled boolean false Disable the input
readonly boolean false Make the input read-only
required boolean false Mark as required
error string '' Error message to display
hint string '' Hint text displayed below the input
locale string auto Locale for date formatting (e.g., 'de-AT', 'en-US'). Uses locale service or browser default.
dateFormatConfig DateFormatConfig - Date format and first day of week
clearable boolean true Whether to show a clear button when a value is selected

Outputs

Name Type Description
valueChange Temporal.PlainDateTime | null Emits when the selected datetime changes
