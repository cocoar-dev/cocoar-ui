DateTime Picker

A strongly-typed datetime picker that returns Temporal.PlainDateTime exclusively. This component always returns a date with time.

Type Safety: This picker only returns Temporal.PlainDateTime | null. For date-only values, use coar-plain-date-picker.
Examples API Docs

Basic Usage

A datetime picker with label and placeholder. Returns Temporal.PlainDateTime | null.

Selected: {{ formatDateTime(basicDateTime()) }}
Type: Temporal.PlainDateTime | null

Pre-selected Value

DateTime picker with an initial value set.

Selected: {{ formatDateTime(preselectedDateTime()) }}

Time Format

Control the time format display: 24-hour, 12-hour with AM/PM, or auto-detect from locale.

24h: {{ formatDateTime(time24h()) }}
12h: {{ formatDateTime(time12h()) }}

Minute Step

Control the granularity of minute selection with the minuteStep input.

Min/Max Constraints

Restrict selectable datetime range. Note: min and max are typed as Temporal.PlainDateTime. When selecting the boundary date (today or 3 months from now), the time picker will also be constrained to the allowed time range.

Selected: {{ formatDateTime(constrainedDateTime()) }}
Range: {{ formatDateTime(minDateTime) }} to {{ formatDateTime(maxDateTime) }}

Size Variants

Available in four sizes: extra-small, small, medium (default), and large.

States

DateTime pickers can be disabled, readonly, show errors, or be marked as required.

Week Numbers

Display ISO week numbers on the left side of the calendar.

Date Markers

Highlight special dates like holidays with markers. Markers show in the side panel when that date is selected.

Selected: {{ formatDateTime(markerDateTime()) }}

Full Featured Example

All features combined: week numbers, weekend highlighting, markers, and 15-minute intervals.

Selected: {{ formatDateTime(fullFeaturedDateTime()) }}
