Overlay API

OverlayBuilder Methods

Method Description
withPreset(preset) Apply a preset configuration (coarMenuPreset, coarModalPreset, etc.)
anchor({{ '{' }} kind, ... {{ '}' }}) Set anchor: 'element', 'point', or 'virtual'
position({{ '{' }} placement, offset, flip, shift {{ '}' }}) Configure positioning behavior
backdrop({{ '{' }} kind, closeOnBackdropClick {{ '}' }}) Add backdrop: 'none', 'transparent', or 'modal'
dismiss({{ '{' }} outsideClick, escapeKey {{ '}' }}) Configure dismiss behavior
attachment({{ '{' }} strategy, container {{ '}' }}) Attach to 'body' or 'parent' container
scroll({{ '{' }} strategy {{ '}' }}) Set scroll strategy: 'reposition', 'close', or 'noop'
a11y({{ '{' }} role, label {{ '}' }}) Set accessibility attributes
fromTemplate(template) Use TemplateRef as content
fromComponent(component) Use Component as content

OverlayOpener Methods

Method Description
open(context) Open as root overlay, returns OverlayRef
openAsChild(parent, context, options) Open as child of parent overlay

OverlayRef Methods

Method Description
close() Close the overlay (and all children)
updatePosition() Recalculate position
