Motion

Timing and easing tokens for consistent, accessible animations across the UI.

Duration

How long animations take to complete. Use shorter durations for small/simple changes, longer for complex/large movements.

--coar-duration-[instant|fast|normal|slow|slower|slowest]
@for (token of durationTokens; track token.name) {
{{ token.name }} {{ token.value }} {{ token.description }}
}

Easing

How animations accelerate and decelerate. Based on Material Design motion principles.

--coar-ease-[linear|out|in|in-out|bounce]
@for (token of easingTokens; track token.name) {
{{ token.name }} {{ token.description }}
}

Transitions

Pre-composed transition values combining duration and easing for common use cases.

--coar-transition-[default|fast|colors|transform|opacity|shadow]
@for (token of transitionTokens; track token.name) {
{{ token.name }} {{ token.description }}
}

Accessibility

All motion tokens respect the prefers-reduced-motion media query. When users prefer reduced motion, all durations automatically become 0ms.
