Card API

Inputs

Name Type Default Description
color 'neutral' | 'outlined' | 'success' | 'warning' | 'error' | 'info' | 'accent' 'neutral' Semantic color variant
padding 'none' | 'sm' | 'md' | 'lg' 'md' Internal padding size
elevated boolean false Add box-shadow for depth
borderless boolean false Remove the border

Content Slots

Directive Description
coar-card-header Header section with bottom border
coar-card-footer Footer section with top border
coar-card-inset Makes a footer flush with the card edges (no padding). Combine with coar-card-footer.
