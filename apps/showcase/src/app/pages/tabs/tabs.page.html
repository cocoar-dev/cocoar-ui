Accessibility

The tabs component follows WAI-ARIA Tabs Pattern:

  • Tab list has role="tablist"
  • Each tab button has role="tab"
  • Each panel has role="tabpanel"
  • Active tab has aria-selected="true"
  • Panels are linked via aria-controls and aria-labelledby
  • Disabled tabs have aria-disabled="true"
