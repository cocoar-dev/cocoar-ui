CoarTabGroupComponent Inputs

Name Type Default Description
activeTab string First tab's ID ID of the currently active tab

CoarTabGroupComponent Outputs

Name Type Description
activeTabChange EventEmitter<string> Emits when the active tab changes

CoarTabComponent Inputs

Name Type Default Description
id string - Unique identifier for the tab
content TemplateRef | Type - Template or component to render as content
contentInputs object {{ '{}' }} Inputs to pass when using component content
disabled boolean false Whether the tab is disabled
loadingStrategy 'lazy' | 'eager' 'lazy' When to load the content
