Selects

Select components for single and multiple value selection. Choose between dropdown (Single/Multi Select) or inline tag-based (Tag Select) variants.

Single Select

Select a single option from a dropdown list. Supports search/filter, keyboard navigation, and object values via compareWith.

Basic Usage

Simple dropdown for selecting one option.

Selected: {{ singleValue() || 'none' }}

Searchable

Enable search/filter functionality for longer lists.

Object Values with compareWith

If option values are objects, provide compareWith to match by a stable key.

Selected value (full object): 
{{ selectedCountryObject() | json }}

States

Disabled, readonly, required, and error states.
Single Select API

Inputs

Name Type Default Description
value T | null null Current selected value (two-way bindable)
options CoarSelectOption[] [] Available options to choose from
label string '' Label text displayed above the select
placeholder string 'Select...' Placeholder text when no option selected
size 'xs' | 's' | 'm' | 'l' 'm' Select size
clearable boolean false Show clear button when value selected
searchable boolean false Enable search/filter in dropdown
searchPlaceholder string 'Search...' Placeholder for search input
compareWith (a, b) => boolean === Function to compare option values
disabled boolean false Disable the select
readonly boolean false Make the select read-only
required boolean false Mark as required (shows asterisk)
error string '' Error message to display
hint string '' Hint text below the select

Outputs

Name Type Description
valueChange T | null Emits when the selected value changes

Tag Select

Select multiple values and display them as removable tags. Optionally allows creating new tags.

Basic Usage

Selected values are shown as removable tags.

Selected: {{ tags().join(', ') || 'none' }}

Allow Create

Create new tags that don't exist in the options.

Type a new tag name and press Enter, comma, or Tab to create it.

maxTags

Limit how many tags can be selected.
Tag Select API

Inputs

Name Type Default Description
value T[] [] Current selected values (two-way bindable)
options CoarSelectOption[] [] Available options to choose from
label string '' Label text displayed above the select
placeholder string 'Add tags...' Placeholder text in the input
size 'xs' | 's' | 'm' | 'l' 'm' Select size

disabled boolean false Disable the select
readonly boolean false Make the select read-only

error string '' Error message to display
hint string '' Hint text below the select

Outputs

Name Type Description
valueChange T[] Emits when the selected values change

Accessibility

All select components support full keyboard navigation and screen reader compatibility.

Keyboard Navigation

Comprehensive keyboard support for dropdown navigation and selection.

Enter / Space Open dropdown or select option
Escape Close dropdown
↓ / ↑ Navigate through options
Home / End Jump to first/last option
Tab Close dropdown and move focus
Type Filter options (when searchable)

Screen Reader Support

Proper ARIA attributes ensure selects work seamlessly with assistive technologies.

  • Label announces with select focus
  • Selected value communicated to screen readers
  • Dropdown state (open/closed) properly indicated
  • Option count and position announced during navigation
  • Required, disabled, and error states clearly communicated

Choosing the Right Select

Each select variant is optimized for different use cases.

Single Select

For selecting one option from a list.

  • Choose a country, category, or status
  • Dropdown with search for long lists
  • Supports object values with compareWith
  • Optional clear button

Multi Select

For selecting multiple options from a list.

  • Choose skills, tags, or permissions
  • Checkboxes within dropdown
  • Selected count badge on trigger
  • Clear all button

Tag Select

For selecting multiple options with inline tag display.

  • Visual tag chips show all selections inline
  • Remove tags individually with × button
  • Best for 1-5 selections (more uses Multi Select)
  • Great for filters, labels, and categories
