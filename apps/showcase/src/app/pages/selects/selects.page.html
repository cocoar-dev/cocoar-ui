Selects

A family of select components for different selection needs: single select, multi-select with checkboxes, and tag-based selection with optional tag creation.

Examples API

Single Select

Basic Usage

Simple dropdown for selecting one option from a list.

Selected: {{ singleValue() || 'none' }}

Searchable

Enable search/filter functionality for long option lists.

Object Values with compareWith

When option values are objects and come from different sources (e.g., options from one API, form value from another), use compareWith to match them by a property like ID instead of reference equality.

Selected value (full object): 
{{ selectedCountryObject() | json }}
The form value and options are different object instances, but compareWith matches them by id.

States

Various states including disabled, readonly, required, and error.

Sizes

Available in xs, sm, md, and lg sizes to match other form components.

Multi Select

Basic Usage

Select multiple options with checkboxes.

Selected: {{ multiValue().join(', ') || 'none' }}

Select All & Searchable

Enable "Select All" option and search functionality.

Sizes

Multi-select available in all standard sizes.

Tag Select

Basic Usage

Tag-based selection displaying selected items as removable chips.

Selected: {{ tagValue().join(', ') || 'none' }}

Allow Create

Allow users to create new tags that don't exist in the options.

Type a new tag name and press Enter or comma to create it.

Sizes

Tag select available in all standard sizes.

Dropdown Position

Opens to Top

When opening to the top, the options are reversed so the first option remains nearest to the input. The dropdown also scrolls to show the first options. Headers like search and "Select All" also appear at the bottom.
