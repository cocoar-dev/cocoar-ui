Progress Bar API

Inputs

Name Type Default Description
value number 0 Current progress value (0 to max)
max number 100 Maximum progress value
variant 'accent' | 'success' | 'warning' | 'error' 'accent' Color variant
size 's' | 'm' | 'l' 'm' Bar height (2px / 4px / 8px)
indeterminate boolean false Show indeterminate animation
label string '' Accessible label (aria-label)
showValue boolean false Display percentage text
