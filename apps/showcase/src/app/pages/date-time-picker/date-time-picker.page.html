Date Time Picker

A two-column date-time picker with scrollable calendar, month navigation, and optional time selection. Supports both date-only and datetime modes using the Temporal API.

Examples API Docs

Date-only Mode

Use mode="date" for calendar-only selection without time picker. Returns Temporal.PlainDate.

Selected: {{ formatValue(basicDateOnly()) }}

DateTime Mode (Default)

The default mode includes both calendar and time picker. Returns Temporal.PlainDateTime.

Selected: {{ formatValue(basicDateTime()) }}

Pre-selected Value

Date-time picker with an initial value set.

Selected: {{ formatValue(preselectedDateTime()) }}

Time Format (12h / 24h)

Control the time format explicitly or let it auto-detect from locale. Set use24Hour="auto" (default) for locale-based detection.

Minute Step

Control the minute increment using minuteStep. Available values: 1, 5, 10, or 15.

Min/Max Constraints

Restrict selectable dates using min and max properties.

Selected: {{ formatValue(constrainedDateTime()) }}
Range: {{ formatValue(minDateTime) }} to {{ formatValue(maxDateTime) }}

Size Variants

Available in four sizes: extra-small, small, medium (default), and large.

States

Date-time pickers can be disabled, readonly, show errors, or be marked as required.

Locale Support

The date-time picker adapts to different locales for date format, weekday names, month names, and time format (12h/24h auto-detection).

Date Markers

Highlight special dates (holidays, events) with markers that show in the calendar.

Selected: {{ formatValue(markerDateTime()) }}

All Features Combined

Combining week numbers, date markers, highlighted weekends, and date-time selection.

Selected: {{ formatValue(fullFeaturedDateTime()) }}

Note: The original coar-date-picker component is still available for simpler use cases where you only need date selection with a compact single-month calendar. Use coar-date-time-picker when you need the new two-column layout with scrollable calendar and/or time selection.
