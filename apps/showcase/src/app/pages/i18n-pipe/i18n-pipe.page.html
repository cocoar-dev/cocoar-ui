Usage

Use the pipe in templates and pass either a fallback string or a params object (plus optional fallback).

Setup

Provide COAR_I18N_PROVIDER (required) and COAR_I18N_EVENTS (optional). If events are omitted, the pipe still works, but won't automatically update when the language changes.
