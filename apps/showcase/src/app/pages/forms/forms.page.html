Best Practices

Guidelines for consistent form layouts.

  • Always use the same size for inputs and buttons in inline forms
  • Use s for compact UI like toolbars or data tables
  • Use m (default) for most forms and dialogs
  • Use l for prominent forms like login or hero sections
  • Required fields should have the required attribute for accessibility
