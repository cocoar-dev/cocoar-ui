Multi Select

Select multiple options with checkboxes. Supports search/filter, optional "Select All", and display truncation via maxDisplayItems.

Basic Usage

Select multiple options. The trigger shows selected labels.

Selected: {{ selectedSkills().join(', ') || 'none' }}

Select All & Searchable

Enable "Select All" and filter the list. Select All only appears when the search box is empty.

maxDisplayItems

Limit how many selected labels are shown before switching to "N selected".

Sizes

Available in xs, sm, md, and lg sizes.

Dropdown Position (Top)

Prefer opening upwards with dropdownPositionPreference.
Multi Select API

Inputs

Name Type Default Description
options CoarSelectOption<T>[] [] Array of options to display
value T[] [] Currently selected values (two-way bindable)
label string '' Label text displayed above the input
placeholder string '' Placeholder text when no selection
hint string '' Hint text below the input
error string '' Error message to display
size 'xs' | 'sm' | 'md' | 'lg' 'md' Input size
searchable boolean false Enable search/filter functionality
searchPlaceholder string 'Search...' Placeholder for search input
showSelectAll boolean false Show "Select All" option
maxDisplayItems number Infinity Max labels shown before "N selected"
dropdownPositionPreference 'bottom' | 'top' 'bottom' Preferred dropdown position
disabled boolean false Disable the select
readonly boolean false Make the select read-only
required boolean false Mark as required (shows asterisk)

Outputs

Name Type Description
valueChange T[] Emits when selected values change
