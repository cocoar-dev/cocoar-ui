Radio Group

Radio buttons allow users to select exactly one option from a set. Use radio groups when users need to see all available options and make a mutually exclusive choice.

Basic Usage

A simple radio group with three options. Default layout is vertical.

Vertical Layout

Options stacked vertically with descriptive labels. Best for longer option text.

@for (color of colors; track color.value) { {{ color.label }} — {{ color.description }} }

Selected: {{ colorSelection() }}

Horizontal Layout

Options displayed side by side. Best for short labels and limited options.

Accessibility

Radio groups are fully accessible with keyboard navigation and screen reader support.

Keyboard Navigation

Full keyboard support for navigation and selection.

Tab Move focus to the radio group
↑ ↓ Navigate between options (vertical)
← → Navigate between options (horizontal)
Space Select the focused option

Screen Readers

Each radio button is properly labeled and announces its state and position.

  • Announces "Option 1, radio button, 1 of 3, selected"
  • Group role with proper labeling
  • State changes announced automatically
Radio Group API

CoarRadioGroup Inputs

Name Type Default Description
name string (required) Form control name for the radio group
label string '' Accessible label for the group (sets aria-label)
orientation 'vertical' | 'horizontal' 'vertical' Layout direction of radio buttons
size 's' | 'm' | 'l' 'm' Size of radio buttons in the group
disabled boolean false Disable all radio buttons in the group
required boolean false Mark the group as required (sets aria-required)
error string '' Error message displayed below the group
hint string '' Hint text displayed below the group

CoarRadio Inputs

Name Type Default Description
value any - Value of the radio button (required)
disabled boolean false Disable this specific radio button

CoarRadioGroup Outputs

Name Type Description
valueChange T Emits when the selected value changes
