Radio Group

Radio buttons allow users to select exactly one option from a set. Use radio groups when users need to see all available options and make a mutually exclusive choice.

Accessibility

Radio groups are fully accessible with keyboard navigation and screen reader support.

Keyboard Navigation
  • Tab - Move focus to the radio group
  • ↑ ↓ - Navigate between options (vertical layout)
  • ← → - Navigate between options (horizontal layout)
  • Space - Select the focused option
 Screen Readers

Each radio button is properly labeled and announces its state (selected/unselected) and position within the group.
