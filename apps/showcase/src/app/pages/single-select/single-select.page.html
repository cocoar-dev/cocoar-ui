Single Select

Select a single option from a list. Supports search/filter, keyboard navigation, and object values via compareWith.

Basic Usage

Simple dropdown for selecting one option.

Selected: {{ singleValue() || 'none' }}

Searchable

Enable search/filter functionality for longer lists.

Object Values with compareWith

If option values are objects and the current value is a different object instance, provide compareWith to match by a stable key (e.g. id).

Selected value (full object): 
{{ selectedCountryObject() | json }}
The form value and options are different object instances, but compareWith matches them by id.

States

Disabled, readonly, required, and error states.

Sizes

Available in xs, sm, md, and lg sizes.

Dropdown Position (Top)

Use dropdownPositionPreference to prefer opening to the top.
Single Select API

Inputs

Name Type Default Description
options CoarSelectOption<T>[] [] Array of options to display
value T | null null Currently selected value (two-way bindable)
compareWith (a: T, b: T) => boolean === Custom comparison function for object values
label string '' Label text displayed above the input
placeholder string '' Placeholder text when no selection
hint string '' Hint text below the input
error string '' Error message to display
size 'xs' | 'sm' | 'md' | 'lg' 'md' Input size
searchable boolean false Enable search/filter functionality
searchPlaceholder string 'Search...' Placeholder for search input
dropdownPositionPreference 'bottom' | 'top' 'bottom' Preferred dropdown position
disabled boolean false Disable the select
readonly boolean false Make the select read-only
required boolean false Mark as required (shows asterisk)

Outputs

Name Type Description
valueChange T | null Emits when selected value changes
