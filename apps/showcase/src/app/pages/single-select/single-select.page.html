Single Select

Select a single option from a list. Supports search/filter, keyboard navigation, and object values via compareWith.

Examples API Docs

Basic Usage

Simple dropdown for selecting one option.

Selected: {{ singleValue() || 'none' }}

Searchable

Enable search/filter functionality for longer lists.

Object Values with compareWith

If option values are objects and the current value is a different object instance, provide compareWith to match by a stable key (e.g. id).

Selected value (full object): 
{{ selectedCountryObject() | json }}
The form value and options are different object instances, but compareWith matches them by id.

States

Disabled, readonly, required, and error states.

Sizes

Available in xs, sm, md, and lg sizes.

Dropdown Position (Top)

Use dropdownPositionPreference to prefer opening to the top.
