Popover

The popover is a lightweight overlay for rich tooltip-like content. It supports hover/focus for desktop and click/tap for touch.

Basic (Hover / Focus)

Default behavior: opens on hover and focus. Use for non-critical, informational content.

Click / Tap (Pinned)

Touch-friendly behavior: click opens and pins the popover. Click outside (or click the trigger again) to close.

Non-Interactive Overlay

When interactive is false, the panel does not capture pointer events. This is useful when the overlay must not block interactions below it (for example: calendar day cells).

The popover panel will not be scrollable/clickable when interactive is false.

Popover API

Inputs

Name Type Default Description
openOnHover boolean true Open popover on hover/focus
openOnClick boolean false Open popover on click (pins it open)
interactive boolean true Whether the popover panel captures pointer events
placement Placement 'bottom' Preferred placement of the popover
offset number 8 Distance from trigger in pixels
enterDelay number 100 Delay before opening on hover (ms)
leaveDelay number 100 Delay before closing on mouse leave (ms)
