Tag

Tags are labels for categorizing, labeling, or marking content. Unlike badges (used for counts and status dots), tags are interactive and can be closed or selected.

Badge vs Tag

When to use each component.

Badge

  • Notification counts (5, 99+)
  • Status dots (online/offline)
  • Attached to other elements
  • Pill-shaped (fully rounded)
  • Read-only, not interactive

Tag

  • Labels and categories
  • Keywords and metadata
  • Standalone elements
  • Slightly rounded corners
  • Can be closable/selectable
