Zoned DateTime Picker

A strongly-typed datetime picker that returns Temporal.ZonedDateTime with full timezone support. Captures user intent (local time + timezone) and can derive UTC instants.

Store Intent, Derive Math: This picker captures the user's intended local time and timezone. The UTC instant is derived and can be recalculated if DST rules change.

Basic Usage

A zoned datetime picker that uses the timezone from CoarTimeZoneService.

Selected: {{ formatZonedDateTime(basicZonedDateTime()) }}
Type: Temporal.ZonedDateTime | null

Intent vs Instant

The key insight: store intent, derive math. ZonedDateTime preserves both what the user meant and what moment that represents.

Why This Matters: If you only store the UTC instant, and DST rules change, a 10:00 AM meeting could become 9:00 AM or 11:00 AM. By storing the local time + timezone, you can always recalculate the correct instant.

Different Timezones

ZonedDateTimePicker works with any IANA timezone. The timezone badge shows where the event "lives".

World Clocks

Same moment shown in different timezones.

Same Moment, Different Clocks:

@if (viennaDateTime()) {

Vienna: {{ formatZonedDateTime(viennaDateTime()) }}
→ Instant: {{ formatInstant(viennaDateTime()?.toInstant() ?? null) }}

}

With Markers

Add date markers to highlight important dates like holidays or events.

Selected: {{ formatZonedDateTime(markerDateTime()) }}
Zoned DateTime Picker API

Inputs

Name Type Default Description
value Temporal.ZonedDateTime | null null Selected datetime (two-way bindable)
label string '' Label text above the input
placeholder string '' Placeholder text when empty
timeZone string from service IANA timezone ID (e.g., 'Europe/Vienna')
min Temporal.ZonedDateTime - Minimum selectable datetime
max Temporal.ZonedDateTime - Maximum selectable datetime
size 'xs' | 'sm' | 'md' | 'lg' 'md' Input size
use24Hour boolean | 'auto' 'auto' Time format (auto uses locale)
minuteStep number 5 Minute selection granularity
showWeekNumbers boolean false Show ISO week numbers
highlightWeekends boolean false Highlight weekend days
markers CoarDateMarker[] [] Special dates to highlight
disabled boolean false Disable the input
readonly boolean false Make the input read-only
required boolean false Mark as required
error string '' Error message to display

Outputs

Name Type Description
valueChange Temporal.ZonedDateTime | null Emits when the selected datetime changes
