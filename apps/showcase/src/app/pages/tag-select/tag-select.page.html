Tag Select

Select multiple values and display them as removable tags. Optionally allows creating new tags.

Basic Usage

Selected values are shown as removable tags.

Selected: {{ tags().join(', ') || 'none' }}

Allow Create

Create new tags that don't exist in the options.

Type a new tag name and press Enter, comma, or Tab to create it.

maxTags

Limit how many tags can be selected. When reached, the inline input is hidden.

Sizes

Available in xs, sm, md, and lg sizes.

Dropdown Position (Top)

Prefer opening upwards with dropdownPositionPreference.
Tag Select API

Inputs

Name Type Default Description
options CoarSelectOption<T>[] [] Array of options to display
value T[] [] Currently selected values (two-way bindable)
label string '' Label text displayed above the input
placeholder string '' Placeholder text when no selection
hint string '' Hint text below the input
error string '' Error message to display
size 'xs' | 'sm' | 'md' | 'lg' 'md' Input size
allowCreate boolean false Allow creating new tags
maxTags number Infinity Maximum number of tags allowed
dropdownPositionPreference 'bottom' | 'top' 'bottom' Preferred dropdown position
disabled boolean false Disable the select
readonly boolean false Make the select read-only
required boolean false Mark as required (shows asterisk)

Outputs

Name Type Description
valueChange T[] Emits when selected values change
tagCreated string Emits when a new tag is created
