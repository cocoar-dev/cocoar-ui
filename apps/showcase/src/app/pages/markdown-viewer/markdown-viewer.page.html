Markdown Viewer API

Component Inputs

Name Type Description
doc MarkdownDocument Pre-parsed markdown document from parse()

Parser Function

Function Description
parse(markdown: string) Parses markdown text into a MarkdownDocument AST

Supported Markdown Features

  • Headings (h1-h6)
  • Bold, italic, strikethrough
  • Inline code and code blocks
  • Ordered and unordered lists
  • Task lists (checkboxes)
  • Blockquotes
  • Links (external open in new tab)
  • Tables
