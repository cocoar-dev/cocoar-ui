Accessibility

Menu components are fully keyboard accessible with proper focus management.

Keyboard Navigation

Navigate and interact with menus using standard keyboard patterns.

Tab Move focus to next menu item
Shift + Tab Move focus to previous item
Enter / Space Activate focused item
Escape Close submenu (when applicable)
Submenus: Expandable menu items can be toggled with Enter or Space, revealing nested menu options.

Screen Reader Support

Menus announce their structure and state to assistive technologies.

  • Menu items announce their label on focus
  • Disabled items communicate non-interactive state
  • Icons provide visual cues (text labels required)
  • Dividers separate logical groups visually
  • Headings provide non-interactive section labels
