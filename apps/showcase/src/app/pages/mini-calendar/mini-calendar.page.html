Mini Calendar

An always-open calendar view for date selection. Use it standalone (e.g. in dashboards, side panels, and forms) or inside other components like the date picker.

Examples API Docs

Basic Usage

A standalone calendar that is always visible.

Selected: {{ formatDate(selectedDate()) }}

Week Numbers

Enable ISO week numbers for business / planning contexts.

Selected: {{ formatDate(weekNumberDate()) }}

Min/Max Constraints

Disable dates outside of a range using min and max.

Selected: {{ formatDate(constrainedDate()) }}
Range: {{ formatDate(minDate) }} to {{ formatDate(maxDate) }}

Locale + First Day of Week

Month and weekday labels are localized using Intl.DateTimeFormat. The calendar start day is controlled by dateFormatConfig.firstDayOfWeek.

German (Monday first)

US (Sunday first)

Selected: {{ formatDate(localizedDate()) }}

Date Markers

Highlight single dates or ranges and show details in a popover on hover/click.

Markers are useful for holidays, events, or availability windows.

Selected: {{ formatDate(markerDate()) }}
