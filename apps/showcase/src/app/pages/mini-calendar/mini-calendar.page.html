Mini Calendar

An always-open calendar view for date selection. Use it standalone in dashboards, side panels, and forms, or inside other components like the date picker.

Basic Usage

A standalone calendar that is always visible.

Selected: {{ formatDate(selectedDate()) }}

Week Numbers

Enable ISO week numbers for business/planning contexts.

Selected: {{ formatDate(weekNumberDate()) }}

Min/Max Constraints

Disable dates outside of a range.

Range: {{ formatDate(minDate) }} to {{ formatDate(maxDate) }}

Date Markers

Highlight single dates or ranges with popover details.

Markers are useful for holidays, events, or availability windows.

Locale & First Day of Week

Month and weekday labels are localized using Intl.DateTimeFormat. The calendar start day is controlled by dateFormatConfig.firstDayOfWeek.

German (Monday First)

European locale with week starting on Monday.

Selected: {{ formatDate(localizedDate()) }}

US (Sunday First)

US locale with week starting on Sunday.
Mini Calendar API

Inputs

Name Type Default Description
value Temporal.PlainDate | null null Selected date (two-way bindable)
min Temporal.PlainDate - Minimum selectable date
max Temporal.PlainDate - Maximum selectable date
locale string 'en-US' Locale for month/weekday labels
dateFormatConfig DateFormatConfig - Date format and first day of week
showWeekNumbers boolean false Show ISO week numbers
highlightWeekends boolean false Highlight weekend days
showTodayButton boolean false Show "Today" navigation button
markers CoarDateMarker[] [] Special dates to highlight

Outputs

Name Type Description
valueChange Temporal.PlainDate | null Emits when the selected date changes
