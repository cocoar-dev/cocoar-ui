Localization (L10n) - Formatting Pipes

Format dates, numbers, currency, and percentages using locale-specific rules.

Multi-source architecture: Intl API provides complete defaults, HTTP source merges business overrides. All pipes are reactive and update automatically when language changes.

Architecture

Understanding the multi-source cascade and loading strategies.

Localization (L10n) - Multi-Source Cascade

  1. Intl Source - Browser Intl API (always first, provides complete defaults)
  2. HTTP Source - Optional JSON overrides for business rules
  3. Custom Sources - Extensible via multi-provider (SignalR, WebSocket, etc.)

Sources are loaded in parallel and deep-merged. Later sources override earlier ones at field level.

Graceful degradation: If HTTP fails (404, timeout, invalid JSON), the system falls back to Intl defaults and logs a warning.

Internationalization (i18n) - Translation Loading

  1. HTTP Loader (default) - Loads from /i18n/{lang}.json
  2. Custom Loaders - Implement CoarTranslationLoader for SignalR, static, IndexedDB, etc.

Translations are cached after first load. Switching back to a previous language is instant.
