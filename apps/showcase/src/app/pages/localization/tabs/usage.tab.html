Formatting Pipes (L10n)

Format dates, numbers, currency, and percentages using locale-aware pipes. All pipes react to language changes automatically.

{{ now | coarDate }} {{ now | coarDate }}
{{ 1234567.89 | coarNumber }} {{ largeNumber | coarNumber }}
{{ 1234.56 | coarCurrency }} {{ price | coarCurrency }}
{{ 1234.56 | coarCurrency:undefined:'EUR' }} {{ price | coarCurrency: undefined : 'EUR' }}
{{ 0.25 | coarPercent }} {{ percent | coarPercent }}

Combined Example

Real-world usage combining multiple formatting pipes.

Date: {{ now | coarDate }}
Items: {{ itemCount | coarNumber: undefined : 0 }}
Subtotal: {{ subtotal | coarCurrency: undefined : 'USD' }}
Tax: {{ tax | coarPercent: undefined : 2 }}
Total: {{ total | coarCurrency: undefined : 'USD' }}

Translation Pipe (i18n)

Translate text content using the coarI18n pipe. Translations react to language changes automatically.

{{ 'showcase.i18nPipe.demo.simpleKey.value' | coarI18n }} {{ 'showcase.i18nPipe.demo.simpleKey.value' | coarI18n }}
{{ 'missing.key' | coarI18n:'Fallback text' }} {{ 'missing.key' | coarI18n: 'Fallback text' }}
{{ 'showcase.i18nPipe.demo.params.value' | coarI18n:{ count: 3 } }} {{ 'showcase.i18nPipe.demo.params.value' | coarI18n: { count: 3 } }}
