Text Input

A versatile text input component for single-line and multiline text entry. Supports prefix/suffix, clear button, and can render as a textarea for longer content.

Accessibility

Text inputs are fully accessible with native keyboard support and screen reader compatibility.

Keyboard Navigation

Standard input keyboard support for text entry and navigation.

Tab Move focus to/from input
Shift + Tab Move focus backward
← → Move cursor within text
Home / End Jump to start/end of text
Ctrl + A Select all text

Screen Reader Support

Labels, hints, and errors are properly associated with inputs.

  • Label text announces with input focus
  • Required state indicated with asterisk and aria-required
  • Error messages linked via aria-describedby
  • Hint text provides additional context
  • Disabled and readonly states properly announced

Text Input API

Inputs

Name Type Default Description
value string '' Current input value (two-way bindable)
label string '' Label text displayed above the input
placeholder string '' Placeholder text when empty
hint string '' Hint text below the input
error string '' Error message to display
prefix string '' Prefix text before the input
suffix string '' Suffix text after the input
size 'xs' | 's' | 'm' | 'l' 'm' Input size
rows number 0 Number of rows (0 = single-line, >0 = textarea)
clearable boolean false Show clear button when input has value
disabled boolean false Disable the input
readonly boolean false Make the input read-only
required boolean false Mark as required (shows asterisk)

Outputs

Name Type Description
valueChange string Emits when the value changes
clear void Emits when the clear button is clicked
