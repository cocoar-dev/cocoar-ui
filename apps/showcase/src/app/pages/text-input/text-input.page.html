Text Input API

Inputs

Name Type Default Description
value string '' Current input value (two-way bindable)
label string '' Label text displayed above the input
placeholder string '' Placeholder text when empty
hint string '' Hint text below the input
error string '' Error message to display
prefix string '' Prefix text before the input
suffix string '' Suffix text after the input
size 'xs' | 'sm' | 'md' | 'lg' 'md' Input size
rows number 0 Number of rows (0 = single-line, >0 = textarea)
clearable boolean false Show clear button when input has value
disabled boolean false Disable the input
readonly boolean false Make the input read-only
required boolean false Mark as required (shows asterisk)

Outputs

Name Type Description
valueChange string Emits when the value changes
clear void Emits when the clear button is clicked
