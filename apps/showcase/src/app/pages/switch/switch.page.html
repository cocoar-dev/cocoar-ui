Switch

A toggle switch for boolean on/off states. Supports labels, sizes, disabled/readonly states, and reactive forms via ControlValueAccessor.

Basic Switch

A simple toggle switch with a label.

State: {{ basicChecked() }}

Pre-checked

A switch that starts in the on state.

State: {{ notificationsChecked() }}

Disabled & Readonly

Disabled switches are greyed out. Readonly ones look normal but cannot be changed.

Sizes

Switches come in three sizes.

Label Position

The label can be placed before or after the switch.
Switch API

Inputs

Name Type Default Description
checked boolean false Switch state (two-way bindable)
label string '' Label text
size 's' | 'm' | 'l' 'm' Switch size
disabled boolean false Disable the switch
readonly boolean false Make the switch read-only
labelPosition 'before' | 'after' 'after' Label position relative to the switch

Outputs

Name Type Description
checkedChange boolean Emits when the checked state changes
