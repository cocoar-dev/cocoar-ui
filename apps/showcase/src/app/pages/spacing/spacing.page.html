Spacing & Effects

Spacing, sizing, and visual effects that create consistent layouts and depth across the design system.

Corner rounding for cards, buttons, inputs, and other UI elements.

Spacing

Margins, padding, and gaps for consistent layout spacing. Based on a 4px grid.

@for (token of spacingTokens; track token.name) {

}

Shadows & Elevation

Box shadows for depth and layering. Higher elevations create more prominent shadows.

@for (token of shadowTokens; track token.name) {
