Tooltip & Popover

Tooltips and popovers are lightweight overlays for extra context. Tooltips are non-interactive hints (hover/focus). Popovers are for richer content and can be touch-friendly.

When to Use Which

Choose the right component based on your use case.

  • Tooltip: short, non-interactive hint. Opens on hover/focus and should not be relied on for touch.
  • Popover: richer content (can include interactive UI). Use click/tap to pin for touch-first flows.
Touch-first: if the content matters on mobile/tablet, prefer a popover that opens on click/tap.

Tooltip & Popover API

CoarTooltipDirective Inputs

Name Type Default Description
coarTooltip string - Tooltip text content
coarTooltipPlacement Placement | 'auto' 'top' Preferred placement
coarTooltipDisabled boolean false Disable the tooltip
coarTooltipOpenDelay number 0 Delay before opening (ms)
coarTooltipCloseDelay number 0 Delay before closing (ms)
coarTooltipClampToViewport boolean true Keep tooltip within viewport
coarTooltipFallbackToBestFit boolean false Use best-fit if preferred placement doesn't fit

CoarPopoverComponent Inputs

Name Type Default Description
openOnHover boolean true Open on hover/focus
openOnClick boolean false Open on click (pinned mode)
interactive boolean true Whether content captures pointer events
placement Placement 'bottom' Preferred placement

Content Projection

Selector Description
[coarPopoverTrigger] The trigger element that opens the popover
[coarPopoverContent] The content to display in the popover panel
