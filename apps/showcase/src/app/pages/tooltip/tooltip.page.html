Tooltip & Popover

Tooltips and popovers are lightweight overlays for extra context. Tooltips are non-interactive hints (hover/focus). Popovers are for richer content and can be touch-friendly.

Examples API Docs

When to use which

  • Tooltip: short, non-interactive hint. Opens on hover/focus and should not be relied on for touch.
  • Popover: richer content (can include interactive UI). Use click/tap to pin for touch-first flows.
Touch-first: if the content matters on mobile/tablet, prefer a popover that opens on click/tap.
