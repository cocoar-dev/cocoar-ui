Date Picker

A strongly-typed date picker that returns Temporal.PlainDate exclusively. For datetime values, use coar-plain-date-time-picker.

Basic Usage

A simple date picker with label and placeholder.

Selected: {{ formatDate(basicDate()) }} (Temporal.PlainDate | null)

Pre-selected Value

Date picker with an initial value set.

Selected: {{ formatDate(preselectedDate()) }}

Min/Max Constraints

Restrict the selectable date range.

Range: {{ formatDate(minDate) }} to {{ formatDate(maxDate) }}

Week Numbers

Display ISO week numbers on the left side of the calendar.

Sizes

Available in four sizes: extra-small, small, medium (default), and large.

Size Comparison

All four size variants aligned for comparison.

States

Disabled, readonly, error, and required states.

Formats & Markers

Support for different date formats and special date highlighting.

Date Formats

Different date format configurations for locales.

All three show December 25, 2025 in different formats

Date Markers

Highlight special dates like holidays with markers.

Selected: {{ formatDate(markerDate()) }}

Full Featured

Week numbers, weekend highlighting, and markers combined.

Selected: {{ formatDate(fullFeaturedDate()) }}
Date Picker API

Inputs

Name Type Default Description
value Temporal.PlainDate | null null Selected date (two-way bindable)
label string '' Label text above the input
placeholder string '' Placeholder text when empty
min Temporal.PlainDate - Minimum selectable date
max Temporal.PlainDate - Maximum selectable date
size 'xs' | 's' | 'm' | 'l' 'm' Input size
dateFormatConfig DateFormatConfig - Date format and first day of week
showWeekNumbers boolean false Show ISO week numbers
highlightWeekends boolean false Highlight weekend days
markers CoarDateMarker[] [] Special dates to highlight
disabled boolean false Disable the input
readonly boolean false Make the input read-only
required boolean false Mark as required
error string '' Error message to display
hint string '' Hint text displayed below the input
locale string auto Locale for date formatting (e.g., 'de-AT', 'en-US'). Uses locale service or browser default.
clearable boolean true Whether to show a clear button when a value is selected
closeOnSelect boolean false Whether to close the panel after selecting a date

Outputs

Name Type Description
valueChange Temporal.PlainDate | null Emits when the selected date changes
