Date Picker

A strongly-typed date picker that returns Temporal.PlainDate exclusively. This component always returns a date without time.

Type Safety: This picker only returns Temporal.PlainDate | null. For datetime values, use coar-plain-date-time-picker.
Examples API Docs

Basic Usage

A simple date picker with label and placeholder. Returns Temporal.PlainDate | null.

Selected: {{ formatDate(basicDate()) }}
Type: Temporal.PlainDate | null

Pre-selected Value

Date picker with an initial value set.

Selected: {{ formatDate(preselectedDate()) }}

Min/Max Constraints

Restrict the selectable date range. Note: min and max are typed as Temporal.PlainDate.

Selected: {{ formatDate(minMaxDate()) }}
Range: {{ formatDate(minDate) }} to {{ formatDate(maxDate) }}

Size Variants

Available in four sizes: extra-small, small, medium (default), and large.

States

Date pickers can be disabled, readonly, show errors, or be marked as required.

Week Numbers

Display ISO week numbers on the left side of the calendar.

Date Format Examples

Different date format configurations:

All three pickers show the same date (December 25, 2025) in different formats.
European: {{ formatDate(europeanDate()) }} | US: {{ formatDate(usDate()) }} | ISO: {{ formatDate(isoDate()) }}

Date Markers

Highlight special dates like holidays with markers.

Selected: {{ formatDate(markerDate()) }}

Full Featured Example

All features combined: week numbers, weekend highlighting, and markers.

Selected: {{ formatDate(fullFeaturedDate()) }}
