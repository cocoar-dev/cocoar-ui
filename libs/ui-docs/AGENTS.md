**Format**: Compodoc's documentation.json format includes:

- JSDoc descriptions and examples
- Dependency graphs
- Source code locations

## 🧭 Key Principles

### 1. Naming Conventions

**All naming follows strict patterns:**

- **Component selectors:** `coar-button`, `coar-table`, `coar-text-input`
- **Component classes:** `CoarButtonComponent`, `CoarTableComponent`
- **CSS variables:** `--coar-color-primary`, `--coar-spacing-md`
- **Package names:** `@cocoar/ui-components`, `@cocoar/ui-menu`

📖 **See:** `docs/NAMING.md` (in repository root, not in this package)

### 2. Architecture

**Key patterns:**

- **Framework-pure libraries** - No global CSS, no Tailwind
- **Design tokens only** - All styling via CSS variables (`--coar-*`)
- **Structured logging** - Use `@cocoar/logging`, never `console.log`
- **Nx monorepo** - Workspace orchestration with Angular 21 + Nx 22

📖 **See:** `docs/ARCHITECTURE.md` (in repository root)

### 3. Component Usage

**Example: Button component**

```typescript
import { CoarButtonComponent } from '@cocoar/ui-components';

@Component({
  selector: 'app-example',
  imports: [CoarButtonComponent],
  template: `
    <coar-button
      variant="primary"
      size="medium"
      (click)="handleClick()">
      Click Me
    </coar-button>
  `
})
export class ExampleComponent {
  handleClick() {
    // Handle click
  }
}
```

📖 **See:** `docs/components/buttons/` for full button documentation

### 4. Design Tokens

**Always use CSS variables, never hardcoded values:**

```css
/* ✅ Correct */
.my-component {
  color: var(--coar-color-primary);
  padding: var(--coar-spacing-md);
  border-radius: var(--coar-border-radius-sm);
}

/* ❌ Wrong */
.my-component {
  color: #007bff;
  padding: 16px;
  border-radius: 4px;
}
```

📖 **See:** `docs/foundations/design-tokens.md` (when created)

### 5. Logging

**Use structured logging, not console:**

```typescript
import { Logger } from '@cocoar/logging';

export class MyService {
  private readonly logger = Logger.create('MyService');

  doSomething(userId: string) {
    this.logger.info('Processing user action', { userId });
  }
}
```

📖 **See:** `@cocoar/logging` package documentation

## 📋 Common Tasks

### Adding a Component

When helping users add a Cocoar component:

1. **Check the component guide:** `docs/components/{component-name}/`
2. **Import the component:** From the correct `@cocoar/*` package
3. **Use standalone imports:** Angular 21+ pattern
4. **Follow naming conventions:** `coar-{component-name}` selector

### Styling with Tokens

When helping with custom styling:

1. **Never suggest Tailwind** - Not used in this design system
2. **Use CSS variables** - Check available tokens in `docs/foundations/`
3. **Follow BEM-like naming** - `.coar-button__label`, `.coar-table__row`
4. **Scope styles** - Component-level only, no global CSS

### Debugging Issues

When helping troubleshoot:

1. **Check version compatibility** - Cocoar uses Angular 21 + Nx 22
2. **Review architecture docs** - `docs/ARCHITECTURE.md` (in repo root)
3. **Check component API** - `api/{package-name}.json`
4. **Suggest structured logging** - Replace `console.log` with `@cocoar/logging`

## ⚠️ Important Notes

### Technology Stack

- **Angular:** 21.x (currently 21.0.6)
- **Nx:** 22.x (currently 22.3.3)
- **Node.js:** 20.x or newer (22.x recommended)

**Do not suggest:**
- Angular 22+ features
- Tailwind CSS integration
- Global CSS solutions
- Unplanned major version upgrades

### Documentation Updates

This package is automatically versioned with all other `@cocoar/*` packages:

- Documentation always matches the installed package versions
- No manual version management needed
- Install the same version of `@cocoar/ui-docs` as your other Cocoar packages
