# @cocoar/ui-docs

Complete documentation for the Cocoar Design System.

## 📦 Installation

```bash
pnpm add -D @cocoar/ui-docs
```

**Recommended:** Install as a dev dependency to access documentation locally during development.

## 📖 Usage

### For Developers

Once installed, all documentation is available in `node_modules/@cocoar/ui-docs/`:

```
node_modules/@cocoar/ui-docs/
├── docs/           # Human-readable guides and component docs
├── api/            # Generated API reference (JSON)
├── AGENTS.md       # Guide for AI assistants
└── README.md       # This file
```

### For AI Assistants (GitHub Copilot, Claude, etc.)

AI assistants can access documentation by:

1. **Reading the AI guide:** `node_modules/@cocoar/ui-docs/AGENTS.md`
2. **Browsing component docs:** `node_modules/@cocoar/ui-docs/docs/components/`
3. **Accessing API reference:** `node_modules/@cocoar/ui-docs/api/`

The package metadata includes an `aiAssistant` field to help AI tools discover entry points:

```json
{
  "cocoar": {
    "aiAssistant": {
      "entryPoint": "./AGENTS.md",
      "humanDocs": "./docs/",
      "apiReference": "./api/"
    }
  }
}
```

## 📚 Documentation Structure

- **`docs/components/`** - Component guides, examples, and best practices
- **`docs/consuming/`** - Integration guides for consuming applications
- **`docs/foundations/`** - Design tokens, localization, and core concepts
- **`docs/patterns/`** - Common UI patterns and recipes
- **`docs/reference/`** - Auto-generated API documentation (Markdown)
- **`api/`** - Machine-readable API definitions (JSON, generated by Compodoc)

## 🔄 Generating API Documentation

API documentation is automatically generated from component source code using Compodoc.

To regenerate API documentation:

```bash
pnpm docs:api
```

This will:
1. Extract JSDoc comments from component TypeScript files
2. Parse component inputs, outputs, and methods
3. Generate JSON files in `libs/ui-docs/api/`
4. Create `api/index.json` for package discovery

The generated JSON includes:
- Component metadata (selector, class name)
- Input properties with types and descriptions
- Output events with types
- Method signatures
- Dependency graphs

## 🤖 Version Matching

This package version always matches the corresponding `@cocoar/*` library versions:

- `@cocoar/ui-docs@1.2.0` documents `@cocoar/ui-components@1.2.0`
- `@cocoar/ui-docs@2.0.0` documents `@cocoar/ui-components@2.0.0`

Install the same version as your other Cocoar packages to ensure accurate documentation.
