Accessibility

  • Badges are inline elements that don't interrupt reading flow
  • Use semantic colors consistently (error for urgent, success for positive)
  • Pulse animations respect prefers-reduced-motion
  • Ensure sufficient color contrast for all variants
  • Consider adding aria-label to parent elements for screen readers
