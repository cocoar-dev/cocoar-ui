Table

A simple, styled table component for displaying tabular data consistently.

Examples API

Basic Usage

Tables use alternating row colors by default for better readability.

Name Email Role Status @for (user of sampleData; track user.email) { {{ user.name }} {{ user.email }} {{ user.role }} {{ user.status }} }

Plain

No alternating colors, uses subtle separator lines instead.

Name Email Role Status @for (user of sampleData; track user.email) { {{ user.name }} {{ user.email }} {{ user.role }} {{ user.status }} }

Bordered

Full borders on all cells for a more structured look.

Name Email Role @for (user of sampleData; track user.email) { {{ user.name }} {{ user.email }} {{ user.role }} }

Compact

Reduced padding for data-dense views.

Name Email Role Status @for (user of sampleData; track user.email) { {{ user.name }} {{ user.email }} {{ user.role }} {{ user.status }} }

Accessibility

The table component uses semantic HTML:

  • Uses native <table>, <thead>, <tbody> elements
  • Header cells use <th> for proper screen reader announcements
  • Supports keyboard navigation through native browser behavior
  • Color contrast meets WCAG AA standards
