Quick Rules

✓ Do
  • Use semantic colors (red = error, green = success)
  • Provide feedback — loading states, focus rings
  • Align components — inputs and buttons line up
  • Show clear hierarchy — primary action is obvious
  • Reserve space for dynamic content (zero CLS)
  • Parents control spacing — components have no margins
✗ Don't
  • No gradients — flat colors only
  • No bright/neon accent colors
  • No shadows on shadows — simple elevation
  • No decoration for decoration's sake
  • No layout shifts — content never jumps
  • No margins on components — use gap on parents
