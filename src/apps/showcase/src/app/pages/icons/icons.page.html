Accessibility

  • Icons are decorative by default and hidden from screen readers
  • Use the label input to add accessible text when the icon conveys meaning
  • Icons in buttons inherit the button's accessible name
  • Colors should maintain sufficient contrast with backgrounds
  • Spinning animations respect prefers-reduced-motion

Usage Notes

Adding Custom Icons

Place SVG files in /assets/icons/ and run npm run build:icons to regenerate the icon registry.

Custom Namespaces

Use namespaced icons for customer uploads: name="customer:invoicePaid"

 Performance

Icons are inlined as strings for maximum portability. No external HTTP requests needed.
