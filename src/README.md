# Cocoar UI (Nx workspace)

The **repository root** is `cocoar-ui/`, and the **Nx workspace root** is this folder: `cocoar-ui/src/`.

For repository overview and docs, start at: [../README.md](../README.md)

## Common commands

```bash
pnpm install
pnpm start
pnpm lint
pnpm test
pnpm build
pnpm e2e
```

Clean rebuild (useful when validating release artifacts):

```bash
pnpm nx reset
pnpm build
```
